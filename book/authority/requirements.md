# Requirements

> **`R-idiomatic-reimplementation`** (accepted): **Preserve important concepts through idiomatic Rust**
> Statement: Reimplement Thinkwell in Rust with its important user-facing concepts and behavior, designing Rust architecture rather than translating TypeScript line by line; compatibility details remain open.
> Source: Project owner's Phase 0 assignment, Project goal.

> **`R-scaffolding-boundary`** (accepted): **Keep Phase 0 limited to preparation**
> Statement: Supply the minimal compilable scaffold, manually authored Book, guidance, basic CI, and honest validation evidence without product functionality or a detailed port roadmap.
> Source: Project owner's Phase 0 assignment and approved scaffolding proposal.

> **`R-explicit-authority`** (accepted): **Preserve human control of scope and unresolved decisions**
> Statement: Begin implementation only within a human-approved Ready milestone; keep unresolved product choices open and reconcile durable discoveries into version-controlled project knowledge.
> Source: Project owner's Phase 0 assignment, Decisions already made and Agent startup contract.

> **`R-reproducible-checks`** (accepted): **Pin development tools and record bounded evidence**
> Statement: Pin Rust explicitly, Anchor Book to a reviewed full commit SHA, and its compatible mdBook version; run documented Cargo, Book, and whitespace checks and record exact results without claiming product verification.
> Source: Project owner's Phase 0 assignment, Installation, CI, and Validation requirements; follow-up requests Rust 1.100.0.

> **`R-source-provenance`** (accepted): **Resolve source rights before adaptation**
> Statement: Verify applicable licensing and attribution before copying or adapting substantive source; copy none during Phase 0 and add no project license until the owner chooses one.
> Source: Project owner's Phase 0 assignment, licensing and attribution constraints.

> **`R-publication-authorization`** (accepted): **Keep publication and repository changes separately authorized**
> Statement: Do not commit, push, publish, or change GitHub repository settings without explicit authorization after scaffold review.
> Source: Project owner's Phase 0 assignment, completion boundary.
